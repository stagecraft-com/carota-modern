Carota Interactive Editor

Click in the editor to start typing...

How to use:

  • Click in the editor to position cursor
  • Click and drag to select text
  • Double-click to select a word
  • Type to insert text
  • Select text then click a style button to apply formatting
  • Keyboard: Cmd+B (bold), Cmd+I (italic), Cmd+U (underline)
  • Keyboard: Cmd+Z (undo), Cmd+Shift+Z (redo)
